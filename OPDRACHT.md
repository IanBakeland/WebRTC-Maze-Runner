# WebRTC Desktop - Smartphone Control Assignment

## Opdracht
Bestuur een desktop javascript experience met een smartphone via een WebRTC data channel.

---

## Functionele Vereisten

### Minimum

- [ ] Een 1-op-1 controle via een QR code
- [ ] Je mag een oud schoolproject van jezelf aanpassen om deze functionaliteit in te bouwen
- [ ] Zorg dat de instructies / besturing duidelijk is. Hou het simpel.
- [ ] Je gebruikt webrtc data channels voor de aansturing. Websockets gebruik je enkel en alleen voor de signalling layer.
- [ ] We kunnen je project opzetten door "npm install" en "npm start" uit te voeren. Dit start een lokale webserver, waar je html / css / javascript op gehost worden. Je moet het niet online hosten.
- [ ] Je gebruikt Git + GitHub voor versiebeheer. Zorg dat je wekelijks een werkende MVP op te leveren en gebruik de GitHub Flow workflow.
- [ ] **README.md file**: Markdown file waarin je je development proces stap per stap bijhoud + een kritische reflectie neerschrijft over de hoe je AI gebruikt hebt, welke stukken dit zijn en waar je bijgestuurd hebt.

### Bonuspunten

- [ ] Accelerometer / gyroscoop / andere smartphone sensor input
- [ ] Video / audio channel integratie als een geïntegreerd deel van de experience (dus: de video / audio moet ook nuttig zijn)
